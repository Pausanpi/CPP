# Cpp

## Overview

This repository contains the C++ modules developed as part of the 42 Common Core curriculum.

The project consists of a series of exercises designed to introduce Object-Oriented Programming (OOP) and progressively explore C++ features, from basic syntax and memory management to advanced concepts such as templates, containers and the Standard Template Library (STL).

Each module focuses on specific concepts and programming techniques, building a solid foundation in C++ development.

## Modules

| Module | Main Topics |
|---|---|
| CPP00 | Namespaces, classes, member functions, stdio streams and basic C++ syntax. |
| CPP01 | Memory allocation, references, pointers and switch statements. |
| CPP02 | Ad-hoc polymorphism, operator overloading and Orthodox Canonical Form. |
| CPP03 | Inheritance and class relationships. |
| CPP04 | Subtype polymorphism, abstract classes and interfaces. |
| CPP05 | Exceptions and error handling. |
| CPP06 | C++ type casting. |
| CPP07 | Templates and generic programming. |
| CPP08 | Templated containers, iterators and algorithms. |
| CPP09 | Standard Template Library (STL) containers and algorithms. |

## Technologies

- **Language:** C++
- **Standard:** C++98
- **Environment:** Linux
- **Build System:** Makefile

## Purpose

The main goal of these modules is to develop a deeper understanding of C++ programming, object-oriented design, memory management and reusable code through practical exercises.
